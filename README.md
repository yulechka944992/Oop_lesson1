# ООП Магазин

Учебный проект для изучения объектно-ориентированного программирования на Python.

## Описание проекта

"Этот проект представляет собой ядро для интернет-магазина, реализованное с использованием ООП. Он включает в себя описание основных сущностей, таких как категории и продукты."

## Цели и задачи

Целью проекта является создание структуры для будущего интернет-магазина, где будут проработаны классы и методы для работы с товарами и категориями

## Новая функциональность

- Добавлены классы Product и Category с инициализацией объектов, а также функции для подсчета количества продуктов и категорий.
- Добавлен вспомогательный класс CategoryIterator для итерации по категории продуктов
### Добавлены новые возможности для классов:

**Класс Product**

- **Приватная цена** - защита от прямой модификации
- **Валидация цены** - автоматическая проверка на отрицательные и нулевые значения
- **Подтверждение понижения цены** - интерактивный запрос при снижении стоимости
- **Умное создание дубликатов** - метод `new_product()` автоматически суммирует количество и выбирает максимальную цену при совпадении названий
- **Подсчет всех товаров на складе** - Магический метод __add__ суммирует все товары на складе

**Класс Category**

- **Приватный список продуктов**
- **Добавление продукта в список**
- **Форматированный вывод для пользователя** - вывод товаров в формате "Название продукта, 80 руб. Остаток: 15 шт." с переносом строки


**Для классов Product и Category добавлены строковые отображения для пользователей**


## Инструкции по установке и запуску

Для запуска проекта необходимо клонировать репозиторий, установить зависимости с помощью poetry и запустить скрипт main.py.
