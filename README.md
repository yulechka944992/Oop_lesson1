# ООП Магазин

Учебный проект для изучения объектно-ориентированного программирования на Python.

## Описание проекта

"Этот проект представляет собой ядро для интернет-магазина, реализованное с использованием ООП. Он включает в себя описание основных сущностей, таких как категории и продукты."

## Цели и задачи

Целью проекта является создание структуры для будущего интернет-магазина, где будут проработаны классы и методы для работы с товарами и категориями

## Новая функциональность

Добавлены классы Product и Category с инициализацией объектов, а также функции для подсчета количества продуктов и категорий.

## Инструкции по установке и запуску

Для запуска проекта необходимо клонировать репозиторий, установить зависимости с помощью poetry и запустить скрипт main.py.
